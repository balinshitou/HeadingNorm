# V25 确认集 8 角公平对照：运行前判定标准（2026-09-27，写于脚本首次运行之前）

## 1. 问题
正文表 7（docs/53 主要检验族）的外挂比较都是 HN(α=0) − 原样(ψ=0)。ψ（输入初始参考方向）与 α（规范系约定）都是任意的。
V24（S39、表 S61）只在发现集上、只对原作者 RoNIN ResNet 做了 8 角平均；两批确认集与本文训练的网络没有做。
审稿预演（paper/merged/HeadingNorm_结果汇总与审稿预演_20260927.pdf，M1）的 seed 0、前 60 条 TLIO-confirm 预演显示原样推理的 ψ=0 是其 8 个 ψ 中最差的一个，
因此需要在确认集全集上检查：收益在两侧都取 8 角平均后是否仍成立。

## 2. 数据与模型
- 数据：results/confirm_20260913 的两批确认集缓存（tlio_c 318 条、imunet_c 87 条），清单与 docs/53 相同。
- 模型：ResNet18-YawAug（Sensors_v4_resnet_yaw_s0–3）、ResNet18-MixPCA（Sensors_v4_resnet_mixed_pca_s0–3，只做 ψ 扫描）、
  Transformer-YawAug 与 IMUNet-YawAug（E3_*_yaw_s0–3）、原作者 RoNIN ResNet。训练时 HN（ResNet18_v3_hn_gn）精确不变，直接复用 confirm_20260913 结果。
- 角度：ψ_k = α_k = 2πk/8。U(ψ)：输入水平通道旋 ψ、输出旋回（与 TTA 同一旋转实现）；H(α)：外挂 HN 用 φ = θ_HN − α；
  FA-2(α) = [H(α) 与 H(α+π) 的逐窗速度平均]，α ∈ {0°, 45°, 90°, 135°}（FA-2 对 α 以 π 为周期）；TTA-8 = 8 个 U 分支的速度平均。
- 计分：统一评价方式 ATE（ate_u），与表 7 相同；同时记录 rte_u、ate_lit、ate_shape 供描述。
