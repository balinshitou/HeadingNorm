# 外挂 HN 能否推广到其他架构——运行前判定标准（2026-09-23）

> 登记号 V22。写于任何新推理运行之前。只推理已训练好的冻结权重，不训练。结果写入 docs/92。

## 0. 已知情况的如实披露

- 对象是 `models/e3_backbone_frontend/E3_{transformer,imunet}_yaw_s{0..3}.pt`：本文按同一配方训练的 Transformer 与 IMUNet 随机偏航增强网络（论文 §4.5.2）。它们**是本文训练的，不是第三方权重**。
- **2026-09-12 的 P0 实验（`results/hn_plugin_p0_20260912/summary.json`）已在 RoNIN 训练受试者组、RoNIN 独立受试者组、RIDI、TLIO 测试集上评测过这两个模型外挂 HN**（文献协议，序列级区间）：
  8 格中 7 格显著降低（IMUNet −4.8%/−13.7%/−8.6%/−16.9%；Transformer −8.5%/−5.4%/−4.4%），Transformer 训练受试者组未检出差异（−1.4%）。这些结果从未进入论文。
  因此这 4 个数据集对这两个模型**不再是未见数据**，只作描述。
- 原定的第三方对象"TLIO 官方逐窗权重"（docs/86 S6）无法获得：官方仓库 README 写明需自行生成数据并重新训练，未发布预训练权重。IMUNet 作者权重此前已确认不可用（V07）。

## 1. 问题

外挂 HN 使增强训练网络 ATE 下降这一结果，是否不限于 ResNet18，在另外两种架构（Transformer、IMUNet）上同样成立。

## 2. 数据与口径

- **判定数据**：TLIO 确认集 `tlio_c`（318 条序列，`data/eval/confirm_tlio`）。这两个模型从未在这批数据上评测过。
- **描述数据**：IMUNet 手机测试划分 `imunet`（36 条）与手机确认集 `imunet_c`（87 条）——两者都未评测过，但只有 4 名受试者（受试者区间在 99% 以上水平退化，见 v6 §3.9），只作方向描述；统一口径的 5 个测试集（其中 4 个已被 P0 看过）。
- 推理与计分完全复用 `tools/unified_eval_20260913.py` 的 `_win` 与 `metrics`（统一口径 ATE `ate_u`）。外挂 HN 与 `ours_yaw_hn` 相同：`H.headings(f)[1]` 的角度旋入、输出旋回。
- 聚合：每条序列先对 4 个种子取平均；TLIO 按序列。

## 3. 主要检验族（2 项）

| 编号 | 比较（处理 − 对照），`tlio_c`，统一口径 ATE |
|---|---|
| A1 | Transformer 增强网络外挂 HN − 原样 |
| A2 | IMUNet 增强网络外挂 HN − 原样 |

区间：序列级百分位 bootstrap，10,000 次，种子 20260906；Bonferroni 2 项 → **97.5% 双侧区间**。
单项：上界 < 0 为显著更低；下界 > 0 为显著更高；否则未检出差异。

**判定：**
- **成立**：A1、A2 都显著更低 → 可写"外挂 HN 使三种架构（ResNet18、Transformer、IMUNet）的增强网络在未评测的 TLIO 序列上 ATE 都显著下降"。
- **部分成立**：一项显著更低，另一项未检出差异 → 只对显著的那一种架构写推广。
- **有害**：任一项显著更高。
- **不成立**：两项都未检出差异。

## 4. 描述性结果（95% 区间，不参与判定）

- A1、A2 在 `imunet`、`imunet_c`（序列区间 + 受试者改善数）与统一口径 5 个测试集上的 ATE 差；
- 同一比较的形状 ATE（`ate_shape`）差；
- 有害检查：任一描述数据集上显著更高的情况全部列出。
