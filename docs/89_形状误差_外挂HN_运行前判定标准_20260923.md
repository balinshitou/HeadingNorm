- **P2（官方 ResNet 外挂 HN − 原样）的方向已知**：补充材料表S24 早已列出两者在 5 个测试集上的序列等权形状 ATE，外挂后全部更低（3.293→3.132、4.269→3.969、1.621→1.448、1.554→1.436、4.595→4.167）。区间从未算过。

## 1. 问题

对一个已训练好的逐窗网络，测试时外挂 HN 后，预测轨迹的**形状**是否更接近真值。

## 2. 指标

`ate_shape`：已存在于 `results/unified_eval_20260913/*.json` 与 `results/confirm_20260913/*.json` 的逐（序列，种子）行，
由 `tools/unified_eval_20260913.py::metrics()` 计算：统一口径对齐后，以起点为中心拟合最优复增益 $a^*$（整体尺度＋整体转角，用真值），
修正后剩余的 ATE（逐坐标 RMSE 约定）。它要用真值才能算，是分析用量，不是部署可得量。

聚合与 `tools/unified_significance_20260913.py` 完全相同：每条序列先对种子取平均 → 受试者内对序列平均 → 受试者等权；
TLIO 无受试者信息，按序列计；IMUNet 受试者取 `Subje[ct]+_N`。

## 3. 主要检验族（8 项，参与判定）

| 编号 | 比较（处理 − 对照） |
|---|---|
| P1 | 增强训练 ResNet18 外挂 HN − 原样（`ours_yaw_hn` − `ours_yaw`） |
| P2 | 官方 RoNIN ResNet 外挂 HN − 原样（`ext_resnet_hn` − `ext_resnet`） |

判定数据集（每项 4 个）：

| 数据集 | 文件内名 | 单位 | 区间 |
|---|---|---|---|
| RIDI | `ridi` | 11 名受试者 | 受试者整群 |
| TLIO 官方测试集 | `tlio` | 36 条序列 | 序列 |
| TLIO 确认集（train+val） | `tlio_c` | 318 条序列 | 序列 |
| IMUNet 手机测试划分 | `imunet` | 4 名受试者 / 36 条序列 | **只用序列级区间判定**（n=4 时 99.375% 受试者区间退化，见 v6 §3.9）；受试者改善数另报 |

排除出判定、只作描述：RoNIN 独立受试者组（P1 外挂的发现集）、RoNIN 训练受试者组（受试者样本内）、
IMUNet 确认集 `imunet_c`（与手机测试划分是同一批 4 名受试者，避免重复计同一批人）。两项比较对同一组数据集，保持对称。

区间：百分位 bootstrap，10,000 次，种子 20260906；Bonferroni 8 项 → **99.375% 双侧区间**。

单项判定：区间上界 < 0 → 显著更低（形状更准）；下界 > 0 → 显著更高；否则未检出差异。

**比较级判定（P1、P2 各自）：**
- **成立**：4 个数据集中至少 2 个显著更低，且没有一个显著更高；
- **有害**：任一数据集显著更高；
- **不成立**：其余情况。

**论文可写的主张：**
- P1 成立 → "对随机偏航增强训练的网络，测试时外挂 HN 使轨迹形状更接近真值（预先写定规则、Bonferroni 校正；与 ATE 同批数据，非独立确认）"。
- P2 成立 → 主张扩展到原作者发布的 RoNIN ResNet。
- P1 不成立 → 不写形状更准的主张；表S24 的描述性数字照原样保留，不加任何"形状更准"的解释。

## 4. 描述性结果（95% 区间，不参与判定）

- P1、P2 在 RoNIN 两组与 `imunet_c` 上的形状 ATE 差；
- 两方向帧平均 − 原样（`ours_yaw_fa2` − `ours_yaw`），5 个统一评测集 + 两个确认集；
- 训练时用 HN − 偏航增强（`ours_hn` − `ours_yaw`），同上；
- 形状占比：每项比较中 Δ形状ATE / ΔATE（统一口径），用于说明 ATE 的下降有多少落在形状上；
- |ε_θ| 与 |ε_s|（整体转角、整体尺度）的逐序列中位数变化。
